# Pop It Store

A one-page landing site for a fictional pop-it toy store, built as a teaching project for my web design students at Kodland. Plain HTML, CSS and JavaScript, no frameworks. The site's text is in Spanish.

## What's in it

- Custom cursor
- Sticky navigation with a mobile burger menu
- Hero section, stats, product cards, rules section and a reviews carousel
- Scroll-to-top button

## Structure

```
index.html
css/styles.css
js/main.js
images/
```

## Running it

No build step: open `index.html` in the browser.
